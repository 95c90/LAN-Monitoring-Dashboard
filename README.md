# مراقبة الشبكة المحلية - دليل التثبيت والتشغيل على Windows

تطبيق لمراقبة أجهزة الشبكة المحلية الخاصة فقط عبر فحص ping حقيقي، مع سجل أحداث محفوظ في قاعدة بيانات SQLite ومزامنة فورية بين المستخدمين.

## المتطلبات

- Windows 10 أو Windows 11.
- Node.js الإصدار 20 LTS أو 22 LTS من الموقع الرسمي: https://nodejs.org
- اتصال بالشبكة المحلية المراد مراقبتها.

## التثبيت (مرة واحدة)

1. فك ضغط مجلد المشروع في مكان ثابت، مثل `C:\LanMonitor`.
2. افتح PowerShell داخل مجلد المشروع (انقر بزر الفأرة الأيمن على المجلد مع الضغط على Shift ثم "فتح نافذة PowerShell هنا").
3. نفّذ الأوامر التالية:

```powershell
npm install
npm run build
```

إذا فشل تثبيت `better-sqlite3` بسبب غياب أدوات البناء، ثبّت "Visual Studio Build Tools" مع حزمة "Desktop development with C++" ثم أعد الأمر `npm install`.

## التشغيل

```powershell
npm start
```

ستظهر رسالة تحتوي على عنوان اللوحة. افتح المتصفح على:

http://127.0.0.1:5173

### أول تشغيل

- ستظهر شاشة إنشاء حساب المدير. أدخل اسم مستخدم (3 إلى 32 حرفًا إنجليزيًا أو أرقامًا) وكلمة مرور لا تقل عن 8 أحرف. هذه الخطوة تتم مرة واحدة فقط.
- يبدأ التطبيق في **وضع المحاكاة التجريبي** بأجهزة تجريبية، وتظهر رسالة تنبيه واضحة بذلك.

### التبديل إلى المراقبة الحقيقية

1. من زر **الإعدادات** اختر **مراقبة حقيقية**، ثم احفظ.
2. أضف أجهزتك بعناوين IP الخاصة (مثل `192.168.1.10`). يرفض التطبيق أي عنوان عام أو اسم نطاق.
3. ستظهر حالة كل جهاز (متصل أو غير متصل) وزمن استجابته بعد كل فحص.

## السماح بطلبات ping في جدار حماية Windows

يتطلب الفحص السماح بالرد على ping (ICMPv4) في جدار الحماية:

1. افتح "Windows Defender Firewall with Advanced Security".
2. اختر **Inbound Rules** ثم **New Rule**.
3. اختر **Custom** ثم **Protocols and Ports**، واختر **ICMPv4** واضبط **Specific ICMP types** على **Echo Request**.
4. اختر **Allow the connection** ثم فعّل الشبكة الخاصة (Private) وأعطِ القاعدة اسمًا مثل "LAN Monitor ICMP".

## الوصول من أجهزة أخرى في الشبكة

افتراضيًا تعمل اللوحة على الجهاز نفسه فقط لأسباب أمنية. للوصول من أجهزة أخرى:

```powershell
$env:HOST="0.0.0.0"; npm start
```

ثم افتح من جهاز آخر: `http://<عنوان IP للجهاز>:5173`. وتأكد من السماح بالمنفذ 5173 في جدار الحماية للشبكة الخاصة فقط.

## تغيير المنفذ

```powershell
$env:PORT="8080"; npm start
```

## مكان البيانات والنسخ الاحتياطي

- جميع البيانات (الأجهزة، سجل الأحداث، الحسابات) محفوظة في الملف `data\lan-monitor.db`.
- لأخذ نسخة احتياطية أوقف التطبيق (Ctrl+C) ثم انسخ مجلد `data`.
- لتغيير مكان الحفظ ضع المسار في المتغير `LAN_MONITOR_DATA_DIR`.

## قواعد الأمان

- يقبل التطبيق عناوين IP الخاصة فقط: `10.x.x.x` و`172.16-31.x.x` و`192.168.x.x` و`127.x.x.x`.
- لا يقوم التطبيق بمسح الشبكة ولا يفحص أي نطاق؛ يفحص فقط العناوين التي يضيفها المدير يدويًا.
- الدخول محمي بحساب المدير، وتُحفظ كلمات المرور مشفرة. يتم تقييد محاولات الدخول الخاطئة.

## أوامر التطوير

```powershell
npm run dev        # وضع التطوير مع التحديث الفوري
npm run typecheck  # فحص الأخطاء البرمجية
```

## استكشاف الأخطاء

- **الجهاز يظهر غير متصل وهو يعمل:** تحقق من جدار الحماية (القسم أعلاه) وأن الجهاز يستجيب لـ ping من PowerShell بالأمر `ping 192.168.1.10`.
- **ظهور رسالة "تعذر تنفيذ أمر الفحص":** تأكد من أن الأمر `ping` متاح في النظام ولم يتم حظره من برنامج أمني.
- **المنفذ مستخدم:** استخدم `$env:PORT` كما هو موضح أعلاه.
